# App Launcher

Organize and launch your apps from one place. Add app URLs, create sections, drag to organize. Saves locally to your browser.

## Features
- Add apps with name + URL
- Create section dividers
- Drag to organize
- Click to launch
- Saves to browser localStorage

## To run locally
\`\`\`
npm start
\`\`\`

## To deploy
Push to GitHub and enable GitHub Pages.
